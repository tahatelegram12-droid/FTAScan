# FTA Reporting Process
## Digital Wallets & Mule Accounts

This document provides a step-by-step guide to the FTA reporting process, covering Digital Wallets and Mule Accounts.

## Overview

The purpose of this document is to explain the FTA reporting workflow in a clear and structured manner, making it easier to follow and execute each step.

## Scope

The process covers:
- Digital Wallets reporting
- Mule Accounts reporting
- Excel calculations and data processing
- PowerPoint presentation updates
- Data validation and accuracy checks
- Final report preparation and submission

## Reporting Procedure

### Step 1: Prepare the Source Data
- Collect the required source files for the reporting period.
- Verify that all necessary files are available.
- Ensure the source data is complete before proceeding.

### Step 2: Process Digital Wallets Data
- Open the relevant Digital Wallets data files.
- Review the data and perform the required calculations in Excel.
- Check the results for accuracy and completeness.

### Step 3: Process Mule Accounts Data
- Open the relevant Mule Accounts data files.
- Review the information and perform the required calculations.
- Validate the results against the available source data.

### Step 4: Update the Excel Reports
- Apply the required formulas and calculations.
- Verify that the formulas reference the correct cells and ranges.
- Review the output for missing values, inconsistencies, or errors.

### Step 5: Update the PowerPoint Presentation
- Open the existing FTA reporting presentation.
- Update the relevant tables, figures, and reporting-period information.
- Ensure the presentation reflects the latest validated Excel results.
- Maintain the existing presentation format and structure.

### Step 6: Validate the Final Results
- Cross-check the Excel calculations against the source data.
- Verify that the figures in the PowerPoint presentation match the Excel reports.
- Review the report for inconsistencies and missing information.
- Correct any identified issues before finalising the report.

### Step 7: Finalise and Submit the Report
- Save the final Excel and PowerPoint files.
- Ensure the files are clearly named and stored in the appropriate location.
- Perform a final review before submitting the report to the relevant stakeholders.

## Important Notes

- Always use the correct reporting-period data.
- Do not overwrite source files unless required by the process.
- Verify calculations before updating the presentation.
- Ensure consistency between Excel reports and PowerPoint figures.
- Keep the final files organised for future reference and auditing.
